New Roadmap Model

Define the reusable checklist — each step is one administrative/regulatory procedure, with a RACI role (Responsible / Accountable / Consulted / Informed) per entity involved. Steps can be reordered, edited or removed at any time; changes here don't retroactively affect projects that already loaded this model.

Leave as "Any project type" for a generic checklist reusable across types — or scope it to one, e.g. Early Warning System.

Leave as "Any entity type" if any organization can run this checklist — or restrict it, e.g. Alerta Temprana is regulator-only.
