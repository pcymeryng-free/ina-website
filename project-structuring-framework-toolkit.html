Project Structuring Framework™ Toolkit

The deliverable-by-deliverable toolkit behind INA's Project Structuring Framework™ (F1) — what to produce at each of the five phases, and who owns it.

01
Overview

What This Toolkit Is

The Project Structuring Framework™ produces a fixed set of documents at each phase — not templates to fill in isolation, but a chain where each deliverable feeds the next gate decision. This toolkit lists every deliverable, its purpose, and who is accountable for producing it, so a program office can staff and schedule structuring work before it starts, not discover the gaps mid-phase.

Phase-by-Phase Detail
I

Strategic Diagnosis and Alignment

Confirms the problem is real, the sponsor is aligned, and the project is worth structuring before any budget is committed.

Gate 1 — Go/no-go decision
II

Feasibility, Business Case & Financial Structuring

Turns the diagnosis into a bankable case: technical alternatives, financing sources and a preliminary risk view.

Gate 2 — Investment decision
III

Governance Design and Contractual Model

Locks how the project will be governed and which contract model transfers risk to the vendor, before tendering opens.

Gate 3 — Authorization to launch procurement
IV

Procurement and Implementation

Runs the tender and delivery under active schedule, cost and quality control.

Gate 4 — Solution acceptance
V

Monitoring, Change Management & Continuous Improvement

Sustains adoption, tracks performance, and closes the loop with a lessons-learned record for the next project.

Continuous — no further gate
03
Usage

How to Use This Toolkit

For Sponsors

  • Assign a named owner to every deliverable before Phase I starts, not when the deadline arrives
  • Treat each gate as a real decision point — skipping a gate to save time is how projects lose control later
  • Keep every deliverable in one shared repository, version-controlled and linked to the gate it supported

For Advisors

  • Scale the depth of each deliverable to the project's size — a small FWA rollout doesn't need a submarine-cable-grade Business Case
  • Reuse the Risk Matrix and RACI Matrix from Phase II/III as living documents through Phase V, not one-off artifacts
  • Pair this toolkit with INA's Risk Register Template and Stage-Gate Checklist for a complete structuring kit
